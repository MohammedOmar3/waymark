# Context Layer Index

Route by task:

| If you are... | Read |
|---|---|
| Starting any session | `active/` (all files), then the repo file |
| Working in a repo | `repos/<repo>.md` |
| Debugging an error or exception | `gotchas.md` - grep the error string FIRST |
| Touching cloud resources, services, environments | `platform.md` |
| Changing a build or release pipeline | `pipelines.md` |
| Asked "why is it built this way" | `decisions.md` |
| Opening a PR | `conventions.md` |
| Working with a specific technology | `playbooks/<tag>.md` |
| Looking for prior work on a topic | `waymark brief <terms>` |
| Looking for a prior design, analysis, or writeup | `docs/INDEX.md` |

Never in this layer: secrets, customer data, code structure.
